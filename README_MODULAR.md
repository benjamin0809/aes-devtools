# AES DevTools - 模块化重构说明

## 📁 新的文件结构

```
webbas-devtools/
├── panel_new.html          # 新的主HTML文件（无内联样式）
├── panel_new.js            # 新的主JavaScript入口文件
├── styles/                 # CSS样式文件目录
│   ├── main.css           # 主样式文件
│   └── themes.css         # 主题相关样式
├── js/                    # JavaScript模块目录
│   ├── utils.js           # 工具函数模块
│   ├── aes.js             # AES解密模块
│   ├── network.js         # 网络管理模块
│   ├── storage.js         # 存储管理模块
│   └── ui.js              # UI管理模块
├── panel.html             # 原始HTML文件（保留备份）
├── panel.js               # 原始JavaScript文件（保留备份）
└── README.md              # 原始说明文档
```

## 🔄 重构内容

### 1. HTML文件拆分
- **`panel_new.html`**: 清理后的HTML结构，移除了所有内联CSS样式
- **`styles/main.css`**: 包含所有主要样式，如布局、组件、表格等
- **`styles/themes.css`**: 包含主题变量定义和主题切换相关样式

### 2. JavaScript文件拆分
- **`panel_new.js`**: 主入口文件，负责初始化和协调各模块
- **`js/utils.js`**: 通用工具函数，如复制、格式化、主题管理等
- **`js/aes.js`**: AES解密相关功能，包含密钥管理和解密逻辑
- **`js/network.js`**: 网络请求管理，包含捕获、过滤、显示等功能
- **`js/storage.js`**: 存储管理，包含localStorage和sessionStorage操作
- **`js/ui.js`**: UI交互管理，包含标签页切换、帮助系统等

## 🚀 使用方法

### 1. 替换文件
```bash
# 备份原文件
cp panel.html panel.html.backup
cp panel.js panel.js.backup

# 使用新文件
cp panel_new.html panel.html
cp panel_new.js panel.js
```

### 2. 确保目录结构
```bash
# 创建必要的目录
mkdir -p styles js

# 确保所有模块文件都在正确位置
ls styles/
ls js/
```

### 3. 测试功能
- 打开Chrome DevTools
- 加载AES DevTools扩展
- 检查所有功能是否正常工作

## 📋 模块说明

### `panel_new.js` - 主入口文件
- 负责初始化所有模块
- 协调模块间的通信
- 处理全局事件和功能

### `js/utils.js` - 工具函数模块
- 复制到剪贴板功能
- 时间格式化
- 文件大小格式化
- 主题管理
- 数据导入导出

### `js/aes.js` - AES解密模块
- AES解密核心逻辑
- 密钥管理
- 自动检测加密内容
- 批量解密功能

### `js/network.js` - 网络管理模块
- 网络请求捕获
- 请求过滤和搜索
- 实时统计显示
- 批量操作功能

### `js/storage.js` - 存储管理模块
- localStorage/sessionStorage管理
- 存储项编辑
- 搜索和过滤
- 导入导出功能

### `js/ui.js` - UI管理模块
- 标签页切换
- 帮助系统
- 通知显示
- 错误处理
