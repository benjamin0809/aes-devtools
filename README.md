# AES DevTools - 网络监控与储存管理工具

一个功能强大的Chrome DevTools扩展，用于监控网络请求、AES解密和储存管理。

## ✨ 主要功能

### 🌐 网络监控
- **实时请求捕获**: 支持早期请求捕获，显示待处理状态
- **智能过滤**: 支持URL、方法、状态码、类型的多维度过滤
- **后缀过滤**: 可包含或排除特定文件后缀的请求
- **搜索历史**: 记录搜索历史，支持快速重用
- **实时统计**: 显示请求总数、成功/失败/重定向/待处理数量
- **运行时间**: 显示工具运行时长

### 🔐 AES解密
- **自动解密**: 启用后自动尝试解密请求和响应体
- **手动解密**: 支持手动执行解密操作
- **批量解密**: 批量处理多个请求的解密
- **多模式支持**: 支持ECB和CBC模式
- **密钥管理**: 从sessionStorage.securityObject自动获取密钥

### 💾 储存管理
- **localStorage**: 管理浏览器的本地存储
- **sessionStorage**: 管理会话存储
- **高级搜索**: 支持包含/精确/正则三种搜索模式
- **数据类型过滤**: 按JSON、字符串、数字、布尔值等类型过滤
- **导入导出**: 支持JSON格式的数据导入导出
- **JSON工具**: 格式化、压缩、验证JSON数据

### 🛠️ 增强功能
- **右键菜单**: 支持复制、导出、打开等快捷操作
- **键盘快捷键**: 丰富的快捷键支持，提高操作效率
- **批量操作**: 批量解密、批量导出等批量处理功能
- **主题切换**: 支持浅色/深色主题切换
- **响应式设计**: 适配不同屏幕尺寸
- **帮助系统**: 详细的使用说明和快捷键指南

## 🚀 安装使用

1. 下载扩展文件到本地
2. 在Chrome中打开 `chrome://extensions/`
3. 启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择扩展文件夹
6. 在DevTools中查看"AES DevTools"面板

## ⌨️ 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + F` | 聚焦搜索框 |
| `Ctrl/Cmd + K` | 聚焦搜索框 |
| `Ctrl/Cmd + R` | 刷新储存数据 |
| `Ctrl/Cmd + S` | 保存储存项 |
| `Ctrl/Cmd + E` | 导出数据 |
| `Ctrl/Cmd + D` | 执行AES解密 |
| `Space` | 暂停/恢复监控 |
| `Escape` | 清除搜索 |
| `Delete` | 删除选中的储存项 |

## 🔍 搜索功能

### 搜索模式
- **包含**: 查找包含搜索词的项目（默认）
- **精确**: 完全匹配搜索词
- **正则**: 使用正则表达式进行搜索

### 搜索范围
- **键名**: 在储存项的键名中搜索
- **值**: 在储存项的值中搜索

### 数据类型过滤
- **JSON对象**: 只显示有效的JSON数据
- **字符串**: 只显示纯文本字符串
- **数字**: 只显示数字值
- **布尔值**: 只显示 true/false 值
- **空值**: 只显示空字符串或null值

## 🔐 AES解密配置

扩展会自动从页面的 `sessionStorage.securityObject` 中获取AES密钥：

```javascript
// 页面中的密钥配置示例
sessionStorage.setItem('securityObject', JSON.stringify({
  aesKeyValue: 'your-32-character-aes-key',
  aesIvValue: 'your-16-character-iv'
}));
```

## 📊 网络统计

实时显示网络请求的统计信息：
- 总请求数
- 成功请求数（2xx状态码）
- 重定向请求数（3xx状态码）
- 错误请求数（4xx/5xx状态码）
- 待处理请求数
- 工具运行时间

## 🎨 主题系统

支持浅色和深色两种主题：
- **浅色主题**: 默认主题，适合明亮环境
- **深色主题**: 护眼主题，适合暗光环境
- **自动保存**: 主题选择会自动保存到localStorage
